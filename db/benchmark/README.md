# Benchmark (индексы / EXPLAIN)

Приложение **не загружает** файлы из этой папки при старте.

- Пустая БД: `../clear_cities.sql` (один раз, вручную через `psql`).
- Создание таблиц: `.\gradlew.bat initDb` или старт сервера (только `CREATE TABLE`, без данных).
- `seed_10000_cities.sql` — заготовка без вставки; тестовые 10k строк для индексов добавляйте только если требует задание по индексам.
